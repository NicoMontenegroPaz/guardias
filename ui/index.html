⚖️ Principio de Arrastre de Equidad

El sistema contabiliza de forma acumulativa las guardias realizadas en meses previos. Si algún integrante realizó una guardia de más o de menos en el período anterior, el algoritmo le asignará prioridad inversa en la siguiente generación mensual para balancear el acumulado.
